# Yegon J. Caroline Portfolio

A responsive portfolio for a freelance full stack web developer, built with semantic HTML, Tailwind CSS via CDN, and vanilla JavaScript.

## Live site

https://yegonjcaroline.github.io/yegon-j-caroline-portfolio/

## Run locally

Open `index.html` in a browser, or place this repository in your XAMPP `htdocs` folder and visit `http://localhost/yegon-j-caroline-portfolio/`. Tailwind CSS and Google Fonts load from their CDNs, so an internet connection is needed for those styles and fonts.

## Deployment

GitHub Actions publishes the repository root to GitHub Pages when changes are pushed to `main`. The contact form validates in the browser only and does not send or store submissions.

## Project files

- `index.html` - portfolio content and sections
- `script.js` - mobile navigation, contact form validation, and active section navigation
- `assets/` - profile photo, project previews, and downloadable CV
- `.github/workflows/deploy.yml` - GitHub Pages deployment
